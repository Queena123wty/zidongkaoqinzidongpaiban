📥 手动导入 / 实时更新数据

数据不自动从机器拉取，由你在钉钉里手工导入，导入后全厂实时可见（符合你的选择）。

真实上线时这样用：在钉钉宜搭的「考勤机数据」表单里，点「批量导入 Excel」，把考勤机导出的打卡表一次性灌进去 → 系统自动化规则触发 → 自动考勤、工时统计、人员考勤三张表立刻重算 → 所有在线用户实时看到新数据。下面可体验导入效果。
① 导入考勤机打卡数据

字段：工号 / 日期 / 上班打卡 / 下班打卡

② 导入生产计划

字段：日期 / 产线 / 品项规格 / 计划产量

③ 导入花名册

字段：工号 / 姓名 / 岗位 / 产线班组 / 技能等级 / 是否持证

📄 使用说明 · 搭建向导

这份原型对应你截图里的导航结构，目前内容为空壳 + 少量演示数据，你后面一点一点告诉我内容，我再往里填。

  1. 导航结构：完全复刻截图 —— 工作区顶部「生产信息数据看板」展开 4 项，接着「湖北总厂生产计划」「湖北总厂花名册」，再是「生产部门（8 厂独立）」8 个厂，每厂内部 11 张子表（生产计划 → 参数设置 → 个人考勤日历 → 人员信息 → 考勤机数据 → 技能矩阵 → 品项规格用人 → 品项规格排班 → 人员考勤 → 工时统计与考勤 → 月度考勤数据）。
  2. 数据来源：考勤机打卡、生产计划、花名册均为手动导入，导入后系统自动重算考勤与排班，全厂实时可见。
  3. 权限模型：分厂隔离 + 总厂可见。各厂角色只看到自己厂 11 张子表；总厂/生产部角色额外看到全厂汇总（看板、各厂人力、基地调度、干部梯队、总厂计划、总厂花名册）。点右上角头像切换身份体验。
  4. 自动考勤：考勤机数据 → 工时计算（跨零点自动处理）→ 出勤/迟到/早退/旷工/请假/休息判定 → 加班工时 → 异常标红。改导入数据即刷新。
  5. 自动排班：三步 —— ① 在参数设置填每日产量与排班规则；② 按「产线×品项规格×工序」从技能矩阵自动抓人（主岗 A 优先）；③ 合规校验（重复排班/无证上岗/超时/连续出勤/人力缺口），全绿后回填。
  6. 实时协同：点「🧑‍🤝‍🧑 模拟多人协作」看 3 个厂的人同时编辑，彼此立刻看到对方改动。真实上线用钉钉宜搭表单+报表，天然支持多人并发。
